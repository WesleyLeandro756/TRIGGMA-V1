# TRIGGMA - Brand Guide Rapido

## 1. Essencia da marca

Triggma representa crescimento previsivel via indicacao, fidelizacao e recorrencia.

Pilares:

1. Confianca (SaaS profissional)
2. Performance (crescimento mensuravel)
3. Inovacao (tech + marketing)

## 2. Sistema de logo

### 2.1 Principal

Arquivo: `triggma-logo-primary.svg`

Uso:

- Home
- Landing pages
- Apresentacoes

### 2.2 Horizontal

Arquivo: `triggma-logo-horizontal.svg`

Uso:

- Header
- Navbar
- Rodape

### 2.3 Icone

Arquivo: `triggma-logo-icon.svg`

Uso:

- App icon
- Avatar social
- Splash/loading

### 2.4 Monocromatico

Arquivo: `triggma-logo-monochrome.svg`

Uso:

- Impressao
- Fundos limitados
- Documentos legais

## 3. Regras de aplicacao

1. Nao distorcer o logo.
2. Nao alterar proporcao do simbolo.
3. Nao trocar a paleta principal sem aprovacao.
4. Manter area de respiro minima de 1x altura do simbolo.
5. Evitar fundos com baixo contraste.

## 4. Paleta

- Primary Blue: `#2563EB`
- Innovation Purple: `#7C3AED`
- Accent Cyan: `#06B6D4`
- Premium Dark: `#0B1220`
- White: `#FFFFFF`

## 5. Tipografia sugerida

- Titulos: Inter / Plus Jakarta Sans (600-700)
- Texto: Inter / Manrope (400-500)
