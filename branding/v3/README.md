# Triggma Logo Lab V3 - 10 Modelos

Colecao com 10 modelos de logo para Triggma (cada modelo com versao principal e icone app).

## Diretriz de criacao

- Estilo: tech premium, moderno, marcante
- Inspiracao: linguagem visual minimalista de empresas de tecnologia
- Resultado: conceitos **originais** (sem copia direta de marcas registradas)

## Modelos

1. Nova Minimal
2. Signal Grid
3. Hyper Growth
4. Atlas Tech
5. Momentum X
6. Quantum Link
7. Prime Network
8. Vector Core
9. Carbon Flow
10. Aurora Stack

## Estrutura de arquivos

Para cada modelo:

- `triggma-v3-XX-<nome>-primary.svg`
- `triggma-v3-XX-<nome>-icon.svg`
- `png/triggma-v3-XX-<nome>-primary.png`
- `png/triggma-v3-XX-<nome>-icon.png`

## Observacao

Use primeiro as versoes `*-primary.png` para comparacao rapida.
Depois que escolher seu favorito, podemos refinar somente 1 modelo para virar a versao oficial.
