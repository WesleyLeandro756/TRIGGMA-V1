# Triggma Premium Logo Kit (MVP)

Este pacote contem um modelo de identidade visual premium para a marca Triggma,
com foco em tecnologia, crescimento e marketing.

## Arquivos

- `triggma-logo-primary.svg` -> logo principal (simbolo + wordmark)
- `triggma-logo-horizontal.svg` -> versao horizontal para header/site
- `triggma-logo-icon.svg` -> icone quadrado (app/icon)
- `triggma-logo-monochrome.svg` -> versao monocromatica (preto/branco)
- `triggma-favicon.svg` -> favicon simplificado
- `TRIGGMA_BRAND_GUIDE.md` -> guia rapido de uso

## Conceito do simbolo

O simbolo combina:

- Letra **T** (Triggma)
- Seta de crescimento (resultado de marketing)
- Pontos conectados (rede de indicacao e tecnologia SaaS)

## Paleta principal

- Azul Tech: `#2563EB`
- Roxo Inovacao: `#7C3AED`
- Ciano Engajamento: `#06B6D4`
- Grafite Premium: `#0B1220`
- Branco: `#FFFFFF`

## Uso recomendado

- App/web: `triggma-logo-primary.svg`
- Barra de navegacao: `triggma-logo-horizontal.svg`
- App icon/PWA: `triggma-logo-icon.svg`
- Ambientes monocromaticos: `triggma-logo-monochrome.svg`
